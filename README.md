# markdowneditor-ldxs

MDEditor（本地 Markdown 编辑器）的 PyPI 发布仓库。

- `markdowneditor/` — 包项目（工具本体来自上游 MDEditor 源，PyPI 渠道打包胶水：入口 `mdeditor`）
- `.github/workflows/pypi-publish.yml` — PyPI Trusted Publisher 自动发布（tag `pypi/tool/markdowneditor/{version}` 触发）
